## 预算增殖方程式
### 流动资本配置体系
| 阶段特征         | 资金分配比 | 转化成本阈值 |
|------------------|------------|--------------|
| 冷启动期(0-8h)   | 15%        | 允许+50%     |
| 爬坡期(8-24h)    | 35%        | 控制±15%     |
| 爆发期(24-72h)   | 45%        | 严格锁客单价 |
| 衰退预警期(72h+) | 5%         | 超限即熔断   |
### AI驱动出价算法

def 动态出价系数(广告组):

   流量纯度 = (转化用户设备新度/平均会话时长)*0.6
   
   竞争烈度 = (广告出现位置平均CPM/大盘基准)*1.2
   
   时间势能 = 黄金时段系数 if 18<=时间<23 else 0.8
   
   return 基础出价 × (流量纯度 - 竞争烈度) × 时间势能
